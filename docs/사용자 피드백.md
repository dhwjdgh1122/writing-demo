- 팀원은 이 문서를 읽고 자신의 관찰과 다른 점·추가 질문을 제안할 수 있다. 실행 환경·조작 순서·기대 결과·실제 결과를 함께 남기면 재현에 도움이 된다.

## AI-FEEDBACK-01 — 한 글자 교체의 삭제 안내에 대한 확인 후보

**접수·정리일:** 2026-11-18. [AI 사전 점검](검증%20기록.md#ai-precheck-01)에서 전달받은 에이전트의 의견이다. 실제 사람의 불편 제보와 구분한다.

- 관찰: `주세여→주세요`처럼 한 글자를 교체해도 후보 카드에 `삭제된 내용 있음`이 표시됐다. 비교 캡처에서 해당 문구와 변경 구간을 확인했다.
- 예상 불편: 삭제 안내가 무엇을 뜻하는지 알아보려고 비교 화면을 추가로 열 수 있다는 의견이다. 실행 보고에서 비교를 열었지만 그 원인이 해당 문구였다는 점이나 실제 사람의 혼란은 확인하지 않았다.
- 현재 판단: 교체는 기존 글자 삭제와 새 글자 추가로 표시될 수 있으므로 문구 관찰 자체를 기능 오류로 판정하지 않는다. 수정·새 이슈 생성은 보류하고, 실제 사용자에게 안내를 어떻게 이해하는지 확인할 대상으로 남긴다.
- 기존 [#4](https://github.com/dhwjdgh1122/writing-demo/issues/4)의 원문 비교 안내와 연결되는 후속 검토 가능성이 있다. 이번 기록만으로 #4를 재개하거나 #8 히스토리를 채택하지 않는다.

## FEEDBACK-04 — 내부 사용 점검과 후보·설명 개선 제안

**접수일:** 2026-11-17. 프로젝트를 알고 있는 내부 사용자 오정호 1인의 의견이다. 처음 사용하는 외부 사용자 평가나 팀 전체 합의가 아니다. 안내문을 다듬는 과제로 직접 사용한 뒤 전반적으로 큰 불편은 없었다고 전달했다. 사용자 본인의 브라우저·정확한 입력/출력은 별도로 확보하지 않았다.

| 구분 | 관찰·의견 | 처리 범위 |
|---|---|---|
| 사용성 의견 | 단순 글자 교체에도 ‘삭제된 내용 있음’이 표시돼 중요한 내용이 빠진 것으로 오해할 수 있다는 의견에 동의 | 기존 [#4](https://github.com/dhwjdgh1122/writing-demo/issues/4)와 관련된 검토 후보. 삭제·교체 의미를 구분하는 안내 개선은 이번 구현에 포함하지 않는다. |
| 채택한 소규모 개선 | 적용 직후 ‘교정할 준비가 되었습니다’가 다시 나와 재실행이 필요한 것처럼 보일 수 있음 | [#6](https://github.com/dhwjdgh1122/writing-demo/issues/6)의 추가 범위로 적용 완료 후 원문 확인·다른 문장 선택 안내를 구현한다. 기존 선택·전송 범위 점검을 완료했다고 간주하지 않는다. |
| 사용성 제안 | 완성된 원문을 가져갈 복사 버튼이 없음 | 편의 기능 후보로 기록. 이번에 새 기능으로 채택하지 않는다. |
| 설명 기능 가설 | 결제/결재처럼 혼동하기 쉬운 단어의 뜻과 해당 문맥에서의 선택 이유를 짧게 알려주면 좋겠음 | [#22](https://github.com/dhwjdgh1122/writing-demo/issues/22)와 관련된 후속 제안. 실제로 바꾼 단어 설명과 남은 오류 탐지는 별개다. #22 완료 기준은 확대하지 않는다. |
| 후보 다양성 가설 | 표현이나 단어에 차이가 있는 후보 3개와 각각에 맞는 설명이 있으면 비교하기 좋겠음 | 의미 보존과 유용한 차이를 함께 검토할 제안. 항상 3개를 강제하거나 차이를 위해 의미를 바꾸는 정책을 채택하지 않는다. 현재 최대 3개 제공 범위는 유지한다. |

앞선 AI 사전 점검에서 발견한 사용성 후보 3개에 사용자가 동의한 것이며 독립적인 사용자 발견 3건으로 집계하지 않는다. 단어 설명·후보 다양성이 실제 선택에 도움을 주는지는 미검증이다. AI 점검과 적용 후 안내의 확인 근거는 [검증 기록](검증%20기록.md#applied-guidance-01)에 연결한다.

**후속 반영:** 위 표의 ‘구현한다’는 접수 당시 계획이다. 적용 후 안내는 [PR #24](https://github.com/dhwjdgh1122/writing-demo/pull/24), 선택 유지·전송 범위 확인은 [PR #25](https://github.com/dhwjdgh1122/writing-demo/pull/25)로 main에 반영했다. 11/17 내부 점검과 11/18의 [AI-PRECHECK-01](검증%20기록.md#ai-precheck-01)은 별도 기록이며 같은 실행으로 합산하지 않는다.
