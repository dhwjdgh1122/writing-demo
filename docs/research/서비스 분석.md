# 센틴스파이 서비스 분석

> 역할: 기존 서비스의 환경·사용 흐름·공식 자료와 프로젝트에 필요한 조사 근거를 관리한다. 우리 웹 데모의 구현 범위는 [PRD](../PRD.md), 실제 서비스 사용 사례는 [서비스 사용 기록](서비스%20사용%20기록.md)을 따른다.

공개 자료 조사 기준일은 **2026-11-03**이다. 이후 제공된 화면·팀원 관찰·2차 멘토링 전달 내용을 구분해 보완했다. 이번 문서 정리는 기존 조사 내용의 이관이며 공식 자료를 새로 확인한 결과가 아니다. 가격·버전·기능은 재조사 시 조사일과 함께 갱신한다.

## 서비스와 사용 환경

SENTENCIFY는 북엔드가 운영하는 글쓰기 보조 서비스다. 공식 한국어 표기는 센텐시파이이며, 프로젝트 문서에서는 기존에 사용한 센틴스파이 표기도 유지한다. 북엔드의 별도 서비스인 editorial의 기능을 센틴스파이 기능으로 합쳐 설명하지 않는다. 출처: [서비스 소개](https://sentencify.ai/ko), [북엔드](https://www.bookend.tech/).

| 환경 | 조사에서 확인한 흐름·특성 | 확인의 한계 |
|---|---|---|
| 데스크톱 앱 | 기존 앱에서 문장 선택 → 단축키 호출 → 설정·교정 → 결과 검토·활용. 공식 안내는 Ctrl+C+C를 사용 | 모든 외부 앱과 운영체제에서 호환성을 검증한 것은 아님 |
| 브라우저 확장 | 웹페이지의 선택 문장과 사이드패널을 활용하는 교정 흐름 | 브라우저·버전·설정에 따라 다를 수 있음. 팀원 작동 문제 제보는 사용 기록 참고 |
| 웹 에디터 | 페이지 내부 원문 공간과 교정 패널. 팀원들이 후보 비교·선택·재실행을 관찰 | 데스크톱 앱과 같은 기능·유지관리 상태라고 가정하지 않음 |

출처: [다운로드 안내](https://sentencify.ai/download), [확장 튜토리얼](https://sentencify.ai/tutorial), [웹 에디터](https://sentencify.ai/editor).

## 기능과 화면에서 참고한 점

- 공식 데스크톱 개편 안내에는 스탠다드·맞춤법 교정·간결하게·풍부하게·새로쓰기 모드가 있다. 모드마다 변경 허용 범위가 달라 결과 비교 시 조건을 구분해야 한다. [개편 공지](https://sentencify.ai/blog/sentencify-desktop-update-0-3)
- 제공된 데스크톱 화면에는 언어·카테고리·프롬프트와 선택 문장·교정 문장 영역이 보인다. 추가 제공 화면에는 프리셋·프롬프트 관리도 보였다. 화면만으로 내부 처리나 주변 문맥 접근을 확정하지 않는다.
- 팀원들의 웹 에디터 관찰에서는 변경 강조와 후보 적용을 확인했지만 별도 교정 이유 설명은 보이지 않았다. 이는 관찰 범위의 결과이며 모든 제품·플랜에 설명 기능이 없다는 증거는 아니다.
- 공개 홈페이지의 예시 탭 전환은 준비된 문구가 바뀌는 동작이었다. 이를 실제 AI 호출이나 교정 정확성 검증으로 보지 않는다.

## 2차 멘토링에서 전달받은 정보

아래는 오정호가 전달한 구두 답변·서면 요약에 근거한다. 공식 페이지 재조사나 직접 재현 결과와 구분한다.

| 전달 내용 | 프로젝트에서의 해석 |
|---|---|
| 기업의 주력은 데스크톱이며 웹 에디터의 업데이트는 거의 진행하지 않는다는 취지 | 시제품 화면·흐름을 선택한 배경. 실제 연동 환경 확보를 뜻하지 않음 |
| 단축키 모달을 주요 경험으로 삼고 큰 창은 깊이 사용하는 경우를 고려 | 설명 열람이 기본 교정 흐름을 방해하지 않는지 살펴볼 필요 |
| 선택 문장을 독립적으로 교정하며 주변 글은 활용하지 않음 | 문맥 활용은 기존 동작과 구분할 확장 제안 |
| 한 후보를 고르는 것 외에 여러 후보의 표현을 조합하는 사용자도 있음 | 후보를 선택하지 않았다는 이유만으로 실패로 분류하지 않음 |
| 선택 텍스트의 정확한 화면 위치 파악에는 예외가 있음 | 외부 앱 연동의 기술적 검증이 별도로 필요 |
| 출판향 B2B editorial은 구체적인 교정 사유를 제공 | 별도 서비스의 기능으로 구분 |

## 관찰에서 도출한 문제 가설

| 관찰 근거 | 확인할 가설 | 아직 알 수 없는 것 |
|---|---|---|
| 비슷한 후보·반복 후보, 날짜의 구체성이 줄어든 사례 | 실제 변화와 의미 영향을 설명하면 비교·선택에 도움이 될 수 있음 | 발생 빈도·전체 고객의 불편·설명 효과 |
| 본문 클릭 후 후보 소실과 미선택 후보 복구의 어려움 | 비교 중 결과를 다시 확인하는 흐름이 필요할 수 있음 | 제품별 재현 조건·히스토리 요구 범위 |
| 여러 설정과 모드 | 사용자 의도와 변경 허용 범위를 이해하는 안내가 필요할 수 있음 | 모든 설정을 우리 시제품에 구현해야 하는지 |

구체적인 원문·후보·관찰자는 [서비스 사용 기록](서비스%20사용%20기록.md)을 참고한다. 프로젝트 선정의 해석과 데이터 한계는 [프로젝트 선정 근거](프로젝트%20선정%20근거.md)에서 관리한다.

## 행동 해석 기준과 미확인 사항

- 요청 성공과 사용자에게 결과가 표시된 것은 다르다.
- 후보 클릭과 본문 적용 완료, 수동 재요청과 설정 변경에 따른 자동 실행을 구분한다.
- 재실행은 오류·지연·새 표현 탐색 등 여러 이유로 발생할 수 있다. 불만으로 단정하지 않는다.
- 오정호는 데스크톱 PC 정상 작동을 보고했지만 노트북의 앱 실행 문제는 남아 있다. 정상 작동만으로 교정 품질 전반을 평가하지 않는다.
- 내부 모델·프롬프트·서버 처리 구조, 실제 고객 문제의 빈도, 전체 환경의 후보 수·복구 동작은 확인되지 않았다.
- 실제 앱에 기능을 추가해 시험할 수 있는 환경은 아직 기업에 문의하지 않았다. 확장 방향은 [PRD](../PRD.md)를 따른다.
