# 조건 근거 추출과 고정 문구 조합 진단

2026-11-17 KST / #22 / 기준 코드 `4b20969`. **원문에 없는 자유 요약을 출력하지 않게 해도 조건의 의미를 잘못 판단하는 문제가 남아 서비스에 적용하지 않는다.** 기존 제품 프롬프트·출력 계약·호출 수·화면은 유지한다.

## 실험 방법

지난 [문장별 조건 해석 진단](조건%20해석과%20분류%20분리%20진단.md)에서는 자유 요약에 `경우에만`이라는 뜻이 추가됐다. 이번에는 모델에 조건 구절과 행동 구절을 그대로 복사하도록 하고, 설명은 진단 코드의 고정 문구로 조합했다. 인용하는 행동에는 부정·가능성·문장부호를 보존하도록 했다.

- V1: 모델이 두 문장의 조건·행동과 관계 분류를 반환한다.
- V2: 모델은 조건·행동과 `sameCondition`(동일 의미 여부)만 반환한다. 추가·삭제·교체·유지는 코드가 조건의 유무와 이 값으로 계산한다. 조건이 한쪽이라도 없을 때 `null`이 아닌 값을 내면 모순으로 남기고 조합하지 않는다.
- 두 방식 모두 조건과 행동을 순서대로 연결해 전체 문장을 덮는지, 실제 연속 문자열인지, 행동이 그대로인지 확인한다. 문장 앞의 조건 하나와 동일 행동으로 분리 가능한 짧은 문장만 대상으로 한다. 인용 누락·겹침·다른 행동·관계 모순·400자 초과를 거부한다. **구조 검사는 의미 동일성을 증명하지 않는다.**
- 날짜·수치·역할 등 다른 변화와 여러 조건이 섞인 문장에 일반화하지 않는다. 기존 서비스에 추가 모델 호출·우회·재시도를 넣지 않았다.

제품과 다른 과제·출력 형식이다. 기존 어댑터는 진단 응답을 캡처한 뒤 제품 스키마와 달라 `invalid/schema`를 반환한다. 이는 예상된 형식 불일치다. 앱 HTTP·브라우저 경로는 실행하지 않았고, 진단의 조합 결과가 실제 화면에 표시된 것은 아니다. 원시 제공자 응답 봉투·키·인증 헤더는 보존하지 않았다.

## 발견한 문제

1. **정확히 인용해도 잘못 분류할 수 있다.** 엘리스는 V1·V2 모두 `회원인 경우에만`과 `회원만`을 다른 조건으로 판단했다. 전체 문장·인용 검사를 통과한 뒤에도 잘못된 조건 변화 설명이 조합됐다.
2. **한정 표현 소실을 놓쳤다.** 새 CE-01은 `승인을 받은 경우에만` → `승인을 받으면`이다. Gemini V2는 동일 의미로 판단해 명시적인 `만` 제한 소실을 드러내지 않았다. 실제 무승인 공개가 허용된다고 판단해야 한다는 뜻은 아니다.
3. **형식상 모순을 잡아도 설명은 미제공이다.** CS-02는 조건 없는 환불 불가 문장에 상품 사용 조건을 추가한다. 엘리스 V1은 이를 교체로 분류했고 V2는 조건이 없는 원문에도 `sameCondition: false`를 냈다. 진단 코드는 두 결과를 거부했으며 성공으로 계산하지 않는다.
4. **분류 일치만으로 충분한 설명이 되지 않는다.** Gemini V1의 관계는 6건 모두 맞았지만, CE-01의 고정 문구는 전후 조건 인용과 유지 안내에 머물러 `만`의 소실이 어떤 차이인지 구체적으로 설명하지 않는다. 일괄 템플릿에는 `‘회원인 경우에만’를`처럼 어색한 조사 연결도 있어 사용자에게 바로 제공할 문구가 아니다.

이 판정은 AI 보조 예비 검토다. 이번 진단에서 자유 요약의 과장은 출력 구조상 제거했지만 의미 오류는 제거하지 못했다. 한 번씩의 비교로 어느 모델·방식이 일반적으로 우수하다고 결론 내리지 않는다.

## 결정과 후속 검토

- 두 방식 모두 서비스에 채택하지 않는다. 형식 모순을 조용히 고치거나 분류 실패를 숨기지 않았고, 실패 사례와 처음 응답을 보존했다.
- 조건 추출, 조건 의미 비교, 사용자 설명은 각각 검증해야 한다. 다음 설계의 핵심은 같은 조건을 다르다고 지적하는 오탐과 실제 한정 표현 소실을 놓치는 누락을 함께 줄이는 것이다. 같은 입력에 지시문을 더 붙여 재호출하는 것만으로 완료를 선언하지 않는다.
- 기존 [병합 기준](../교정%20설명%20평가%20기준.md#issue22-merge-gate)은 유지한다. 새 진단 사례는 그 14사례를 교체하지 않는다. 최종 반복 검증·남은 단어 문제·사람의 독립 평가·사용자 효과는 미완료다. #22 진행 중, PR #23 Draft, main 미병합을 유지한다.
