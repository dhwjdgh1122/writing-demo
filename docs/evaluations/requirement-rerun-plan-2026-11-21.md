# 요구 반영 재교정의 실제 연결 제한 점검

2026-11-21. 실제 호출 전에 고정한 계획이다. #49 기능의 요청 연결과 제한된 예시를 점검하며, #22 설명 품질 완료나 사용자 만족·설명 효과 검증을 대신하지 않는다.

## 입력과 최대 호출 수

두 제공자를 각각 독립적으로 실행한다. Gemini `gemini-3.5-flash-lite`, 엘리스 `gpt-4o-mini`를 사용하고 제품 코드의 출력 계약·프롬프트·인용 검사·모델 설정을 그대로 거친다.

1. **적용 전 다른 표현 요구:** 현재/이전 선택 원문은 `금요일까지 자료를 보내 주세요.`, 이전 후보는 `금요일까지 자료를 보내 주시기 바랍니다.`이다. `alternative` 요구로 새 후보를 1회 요청한다.
2. **적용 후 원래 의미 유지 요구:** 현재 문장은 `목요일에 10명에게 안내합니다.`, 이전 선택 원문은 `담당자 확인 후 목요일에 8명에게 안내할 예정입니다.`, 이전 후보는 현재 문장과 같다. `meaning` 요구로 새 후보를 1회 요청한다.
3. **실제로 받은 후보의 설명:** 2번 교정 API가 성공하고 완전한 후보를 반환했을 때만 해당 후보 전체의 설명을 1회 요청한다. 현재 원문과 동일한 재교정 맥락을 보내며, 준비한 후보로 바꾸지 않는다.

제공자당 최대 3회, 총 최대 6회다. 기존 공통 장부의 13회에 모두 더하면 19회이며, 개발·재현 24회 / 최종 84회 / 총 108회 상한을 유지한다. 자동 재시도·다른 모델 대체·실패 출력 제외는 하지 않는다. 제공자 장애·쿼터·시간 초과·연결 설정 실패는 해당 제공자의 남은 호출을 중단한다. 다른 제공자는 독립적으로 진행할 수 있다. 2번의 출력이 중단되거나 API가 실패하면 3번을 건너뛴다.

## 실행 전 판정 기준

- **다른 표현:** 이전 후보와 다른 표현이 실제로 제안됐는지, 금요일이라는 기한과 자료 전달 요청의 의미·강도가 유지됐는지 후보별로 확인한다. 같은 표현만 나왔다면 다른 표현 제공은 확인하지 못한 것으로 기록한다. 제품이 적절한 대안이 없을 때 기존 표현을 허용하는 것과 이 예시에서 요구 충족을 확인한 것은 구분한다.
- **원래 의미:** 이전 선택 원문에 있던 담당자 확인 조건·8명·예정 표현을 새 후보가 유지·복원하는지 확인한다. 목요일 일정도 유지하고, 없는 사실을 추가하지 않아야 한다. 일부 후보의 성공을 모든 후보의 성공으로 표현하지 않는다.
- **설명:** 비교 대상은 현재 `목요일에 10명에게 안내합니다.`와 실제 새 후보다. 실제로 바뀐 숫자·조건·확정 여부를 설명하는지, 이전 원문을 현재 원문으로 혼동하지 않는지, 요구를 전달했다는 이유만으로 충족·정확성·만족을 보증하지 않는지 후보별로 확인한다. 인용 차단·누락·과장도 그대로 기록한다.
- 원문·이전 후보·선택 요구는 실제 기능에 필요한 입력이다. 위 평가 기준이나 정답 설명을 모델 입력에 추가하지 않는다.

API 성공, 실제 후보의 요구 반영, 설명 내용의 정확성은 각각 따로 판정한다. 단일 제공자·사례당 1회 결과로 발생 빈도·일반 성능 점수·모델 우열·설명 효과를 주장하지 않는다. #22의 미완료 상태는 유지한다.

## 재현과 기록

`scripts/check-requirement-rerun.mjs`는 기본적으로 dry-run이다. `--provider=gemini` 또는 `--provider=elice`로 호출 계획과 입력·프롬프트 해시만 확인하며 환경 파일 읽기·파일 생성·모델 호출을 하지 않는다.

실제 실행에는 `--live`, 기존 `MODEL_CALL_LEDGER`가 필요하다. `MODEL_ENV_FILE`을 지정하지 않으면 `.env`를 읽는다. 키·제공자 URL·환경 파일 경로·원시 오류 본문은 기록하지 않는다. 실제 외부 fetch 직전에 공통 장부에서 호출을 예약하고 성공·실패를 기록한다.

제공자별 `requirement-rerun-{provider}-2026-11-21.json`에 커밋·작업 트리 상태·구현 해시·실제 전송 입력·프롬프트 해시·설정·원시 완성 출력·어댑터 결과·API 결과·시간·미실행 항목을 보존한다. 기존 보고서가 있으면 덮어쓰기를 거부한다. UI 동작은 주입 응답을 쓰는 브라우저 테스트에서 별도로 확인한다.
