2026-11-17 KST / #22 / 본평가 코드 `3d6e191`, 별도 미호출 후보 점검 `41af440` / Codex AI 보조 예비 평가. JSON의 UTC 실행일은 2026-11-16이다. 사람의 독립 평가나 사용자 효과 검증은 아니다.

## 결론

**후보별 입력과 ID 연결을 분리했지만 설명 품질 기준은 아직 미충족이다.** 복합 의미 변화와 날짜·오타 구분이 일부 응답에서 확인됐다. 그러나 없는 구절 인용, 출력 형식 위반, 조건을 관계 변화로 잘못 분류한 설명, 미수정 단어 문제의 누락이 남았다. PR #23은 Draft로 유지하고 main에 병합하지 않는다.

## 구현과 비용

- 모델에는 원문과 후보 하나, 해당 후보의 문자열 차이만 보낸다. 다른 후보와 후보 ID는 보내지 않는다. 모델이 반환한 `{changes, notes}`에 서버가 요청 후보의 ID를 연결한다. 모델이 잘못된 ID를 만드는 경로를 제거한 것이며 내용의 정확성을 보장하는 것은 아니다.
- 변경된 후보마다 순차 호출한다. 앱 설명 요청은 1회지만 실제 모델 호출은 최대 3회다. 원문과 같은 후보는 호출하지 않는다. 실패하면 이후 후보를 호출하지 않고 전체 설명 요청을 오류로 처리한다. 부분 결과를 성공 응답으로 보내지 않는다.
- 모든 후보가 기존 45초 제한 시간을 공유한다. 자동 재시도·자동 모델 전환·제한 시간 연장은 없다. 후보 수에 따라 비용과 대기 시간이 늘 수 있다.
- J의 변경 항목·종류별 안내·400자 제한·출처 검사를 유지했다. 교정 후보 생성과 화면·선택·적용 흐름은 바꾸지 않았다.
- 평가에는 모델 호출 시도 수, 호출한 후보 ID, 후보별 입력과 구조 응답을 누적 기록한다. `completed`는 계획한 **앱 요청**을 모두 실행했다는 뜻이다. 그 안에서 첫 후보가 실패해 후속 후보가 미호출일 수 있다.

## 자동 검증과 범위

- 타입 검사·단위/API **69개**·빌드 통과. 기존 64개에 후보별 격리·서버 ID 연결·관찰 누적, 중간 실패 시 후속 호출 중단, 동일 후보 무호출·입력 상한, 취소 후 호출 방지, HTTP 공통 제한 시간과 부분 결과 미노출 검사를 추가했다.

- UI 변경이 없어 로컬 Edge 검사는 반복하지 않았다. PR의 최신 CI에서 기존 브라우저 21개를 별도로 확인한다.

- 평가 3건의 코드·프롬프트·출력 처리·호출 제어·도구·fixture 해시, 실제 입력과 15회 호출을 대조했다. 관련 문서 8개의 내부 링크·앵커 154개를 확인했고, 인증값 혼입 없음·`.env` 해시 불변을 확인했다.
