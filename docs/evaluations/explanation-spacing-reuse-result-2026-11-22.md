# 공백 변경 사실 안내 재사용 결과

2026-11-22 / #22·[Draft PR #55](https://github.com/dhwjdgh1122/writing-demo/pull/55). [계획](explanation-spacing-reuse-plan-2026-11-22.md)에 따라 PR #34 `d2d8c42`의 공백 계산 함수를 현재 자유문 응답 계약에 재사용했다. main에는 아직 반영하지 않았다.

## 바뀐 동작

일반 공백(U+0020) 이외의 모든 글자가 동일한 후보에 한해, 모델이 쓴 적절성 판단 대신 위치별 공백 추가·삭제 개수를 안내한다. M-01 후보 1에는 다음 문구가 표시된다.

> 공백 5개를 추가하고 4개를 삭제했습니다. 원문 비교에서 공백이 바뀐 위치가 의도에 맞는지 확인해 주세요.

이는 바뀐 사실에 한정한 안내다. 공백만 바뀌어도 뜻이 달라질 수 있으며, 맞춤법의 정확성이나 왜 더 적절한지는 보증하지 않는다. 후보 2·3과 같이 공백 외의 변경이 있으면 기존 모델 설명·후보별 오류 처리를 유지한다.

전체 모델 요청·JSON 파싱·후보 ID 검증 뒤에 처리한다. 추가 모델 요청이나 모델 호출 생략은 없으며, 503·시간 초과·전체 JSON/ID 실패는 그대로 실패한다. 개별 공백 후보의 잘못된 모델 설명은 코드 사실로 대체하지만 다른 후보의 오류를 정상 처리하지 않는다.

## 저장된 실제 출력 재처리

[첫 실험의 엘리스 원자료](explanation-freeform-contrast-2026-11-22-elice.json) 중 M-01 기준안·대조안 두 건을 그대로 새 파서와 기존 인용 검사에 입력했다. 원자료 SHA-256 `c18c24ce6980a9bd3bc5bae2163b96754522739fb7752fed461bf94394ee48ba`의 불변을 확인했다. [재처리 원자료](explanation-spacing-replay-2026-11-22.json)는 실행 시각·코드/작업 트리·파일 해시와 전후 결과를 보존한다.

| 대상 | 기존 표시 결과 | 재처리 결과 |
|---|---|---|
| 기준안·대조안 후보 1 | 없는 표현을 인용하여 차단 | 공백 5개 추가·4개 삭제 안내 |
| 기준안 후보 2·3 | 인용 검사는 통과했으나 내용 오류가 있는 설명 | 문자열까지 기존 결과 유지 |
| 대조안 후보 2·3 | 인용 불일치 차단 | 같은 오류 유지 |

**재처리에 따른 실제 모델 호출은 0회다.** 원래 후보 1의 모델 출력 실패를 성공으로 재분류하지 않는다. 모델이 더 정확해졌거나 사용자 판단이 좋아졌다는 결과도 아니다. 최초 실험의 전체 품질 판정은 [미채택 결과](explanation-freeform-contrast-result-2026-11-22.md)를 유지한다.

재현은 저장소 루트에서 `node --import tsx scripts/replay-explanation-spacing.mjs`로 실행한다. 기본은 검증·요약 출력만 하고, `--write`는 결과 파일이 없을 때만 새로 쓴다. 환경 변수 로딩·제공자 연결·네트워크 요청은 없다.

## 자동 검증과 남은 범위

- 타입 검사·단위/API **154/154**·빌드 통과. 빌드의 기존 Zod 주석 위치 경고는 있었으나 종료 코드는 0이었다.
- 로컬 Edge 157의 `workspace.spec.ts` **19/19** 통과. 설명 표시·재사용, 잘못된 ID, 부분 실패 재요청, 늦은 응답 폐기, 비교·적용을 주입 응답으로 검사했다. 기존 Vite WebSocket 포트·색상 환경 경고는 있었으나 종료 코드는 0이었다.
- 새 단위 8개·어댑터/API 4개로 공백 이동/개수, 의미가 달라질 수 있는 사례, Unicode·줄바꿈·탭 경계, 혼합 후보, 잘못된 형식/ID, 정상 설명 보존, 실패한 후보만 재요청, 503 보존과 요청당 1회 호출을 확인했다. API 검사는 응답 주입이며 실제 모델 호출이 아니다.
- 원문 동일 후보의 고정 안내와 개별 형식 오류 처리도 그대로 유지한다. 인용 검사를 완화하거나 새로운 문법 판단 규칙을 만들지 않았다.
- #22의 원래 14사례·두 제공자·3회 반복 기준은 미충족 상태다. 조건·어휘·의미 해석·선택 기준 누락은 별도로 남으며 이번 계산 안내를 모델 설명 품질 점수에 더하지 않는다.

최종 PR CI는 [검증 기록](../검증%20기록.md#explanation-spacing-reuse-01)에 연결한다. 앞선 `aef8e42` CI는 설명 변경 이전의 기록이며 이력 화면 키보드 초점 검사 1개 실패·84개 통과였다. 검사에서 `details.open`만 확인한 뒤 Tab을 누르면 `onToggle`로 렌더링하는 원문 영역이 아직 없을 수 있어, 해당 영역 표시를 기다린 뒤 Tab을 누르도록 보완했다. 강제 포커스·시간 제한 변경 없이 기존 순서 검사를 유지했고 해당 검사 1/1이 통과했다. 직전 main CI도 같은 Edge 158에서 85/85 통과했으므로 버전 회귀로 단정하지 않는다. 실패 당시 trace가 업로드되지 않아 실제 포커스 대상과 근본 원인은 미확인이다.
