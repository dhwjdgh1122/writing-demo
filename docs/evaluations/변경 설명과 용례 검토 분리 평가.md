2026-11-17 KST / #22 / Codex AI 보조 예비 평가. 실제 사용자 평가나 사람의 독립 평가가 아니다.

## 결정

**두 단계 모델 호출은 채택하지 않는다.** 남은 단어 문제를 더 잘 설명하려고 변경 설명과 단어 검토를 나눴지만, 누락·잘못된 지적·인용 실패가 남았다. 정상 승인 문맥의 단어까지 오류로 지적하는 초안도 확인했다. 호출 수를 늘릴 근거가 부족하므로 기존 O의 후보당 1회·최대 3회·공통 45초 처리로 복원했다. 실험 커밋·입력·실패 결과는 보존한다. main에는 병합하지 않는다.

이번 작업에서 **정확히 같은 before/after 쌍을 의미 변화와 단순 수정 양쪽에 중복한 응답을 차단하는 검사**만 남겼다. 다른 구절로 표현한 중복이나 의미 오분류까지 감지하는 기능은 아니다. 역할 변화와 부정 변화처럼 서로 다른 의미 차원은 같은 구절을 인용할 수 있다. 잘못된 응답을 자동으로 옮기거나 삭제해 성공 처리하지 않는다.

## 비용·시간·기록의 한계

- 모델 호출 상한은 후보당 1회에서 2회, 요청당 3회에서 6회로 증가했다. 금액·토큰 사용량은 측정하지 않았으므로 정확한 비용 배수를 말하지 않는다.
- 성공한 P1 Gemini의 단일 후보 요청은 약 2.8~14.1초였다. 세 후보를 모두 완료하는 6호출 요청은 확인하지 못했다. P-01은 첫 후보에서 실패해 45초 안에 모두 끝난다는 근거가 없다.
- P의 `modelDrafts`는 changes와 인용 검사를 통과한 notes 조합을 구분한다. notes 인용 실패의 구체적인 문구는 보존되지 않아 추정하지 않는다.
- Q는 형식을 통과한 notes도 최종 인용·내용·길이 검사 전에 combined로 기록한다. 같은 후보의 changes/combined를 서로 다른 성공으로 세지 않는다. notes는 모델의 주장이지 검증된 용례 판정이 아니다.
- 보고서의 두 지침 해시·입력·시도 단계는 해당 실험 버전 기준이다. 현재 복원된 실행 도구는 다시 기존 한 단계 형식이다. P·Q 재현 시 표의 코드와 도구 버전을 함께 사용해야 한다. 과거 JSON을 현재 도구가 만든 결과로 해석하지 않는다.
