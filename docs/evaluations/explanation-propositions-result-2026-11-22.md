2026-11-22 / #22·Draft PR #55 / 실행 코드 `98cd8be`. 사용자의 「실행」 지시에 따라 [준비된 계획](explanation-propositions-plan-2026-11-22.md)의 최대 6요청만 실행했다. 장시간 목표의 무제한 재개, 후속 판단·설명 생성, 제품 적용·main 병합은 포함하지 않는다.

**결론: 중요한 정보가 보존된 출력은 확보했지만, 같은 의미의 중복과 정확 인용 실패가 남아 현재 구성을 후속 판단이나 제품에 연결하지 않는다.** Gemini의 두 사례는 서비스 실패·미실행으로 내용 평가가 불가능하다. 이번 진단을 #22 설명 품질 통과나 모델 간 우열로 해석하지 않는다.

E-03·엘리스의 실패 부분은 다음과 같다.

```text
원문 일부: …8명에게 자료를 보낼 예정이며, 발송은 확정되지 않았습니다.

```

`예정이며,`를 `예정이다.`로 바꾼 문자열은 원문에 존재하는 연속 인용이 아니다. 명제 statement에서 문장을 정리하는 것과 quote에서 원문을 그대로 복사하는 것은 다른 요구다. 실패한 quote를 코드로 고치거나 검사 기준을 완화하지 않았다. h2·h3의 인용은 각각 해당 출처에 존재한다.

## 해석과 다음 작업의 경계

1. **긍정적인 관찰:** 이번 엘리스 E-03은 별도 미확정을 포함한 주요 정보를 정리했다. 하지만 기존 조건 추출·완성 설명 실험과 과제와 출력이 달라 개선율이나 인과 효과로 비교할 수 없다.
2. **아직 해결되지 않은 부분:** CT-03의 의미 중복은 자동 문자열 검사만으로 해결되지 않으며, 목록 차이를 곧 의미 변화로 사용하면 잘못된 설명으로 이어질 수 있다. E-03의 인용 실패도 현재 출력 계약에서 유효한 근거로 사용할 수 없게 한다.
3. **확대하지 않은 범위:** 후속 독립 논리 판단, 선택 기준·교정 이유 생성, 전체 14사례 반복 평가, 실제 사용자 판단 효과 검증을 수행하지 않았다. 현행 제품과 같은 조건으로 비교한 설명 품질 평가도 아니다.
4. **후속 판단:** 현재 구성을 그대로 반복하거나 제품에 추가하지 않는다. 다음 가설을 검토할 때는 중복·출처 실패를 어떻게 다룰지와 기존 근거 ID·고정 인용 실험과의 차이를 먼저 확인한다. 이번 결과만으로 새 다단계 호출을 도입하지 않는다.
