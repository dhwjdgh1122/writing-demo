# 조건 분류의 변경 구간 입력 제외 진단

- 2026-11-17 KST / #22 / 기준 코드 `0e4df1d`. 서비스 코드·프롬프트·출력 검사·모델은 유지하고 실제 전송 입력에서 `candidate.comparison`만 제외하는 진단을 수행했다.
- 목적: 글자 단위 변경 조각이 조건 유지·삭제 오분류에 영향을 주는지 확인한다. 기존 지침 추가 실험과 별개다.
- 결정: 변경 구간 제거를 서비스에 적용하지 않는다. 일부 응답만으로 원인을 확정하지 않으며, 두 모델의 정확성 문제가 함께 해결되지 않았다.

## 실행 범위

[조건 전이 fixture](../../tests/fixtures/explanation-condition-transfer-cases.json)의 CT-01·CT-02·CT-03·E-07을 사용했다. 모델 제공자 어댑터를 직접 호출했으며 앱 HTTP·화면 경로는 실행하지 않았다. 정상 제공자 HTTP 응답이어도 어댑터 검사에서 차단될 수 있고, 어댑터 반환도 의미 합격은 아니다.

| 제공자 | 입력 | 모델 호출 | 어댑터 반환 | 기록 |
|---|---|---:|---:|---|
| Gemini | 기존 comparison 포함 | 2 | 1 | [기록](baseline-gemini-2026-11-17T06-17-03-735Z.json) |
| 엘리스 | 기존 comparison 포함 | 4 | 0 | [기록](baseline-elice-2026-11-17T06-17-04-200Z.json) |
| Gemini | comparison만 제외 | 4 | 4 | [기록](without-diff-gemini-2026-11-17T06-17-29-285Z.json) |
| 엘리스 | comparison만 제외 | 4 | 2 | [기록](without-diff-elice-2026-11-17T06-17-29-036Z.json) |

총 14모델 호출. 기존 Gemini는 CT-02에서 서비스 오류로 중단해 CT-03·E-07은 실행하지 않았다. 따라서 Gemini CT-03의 이번 비교는 양쪽 응답이 모두 있는 전후 쌍이 아니다. 입력 제외 실행은 별도 진단 조건이며 자동 재시도·성공 결과 대체가 아니다.

## 결과와 한계

- Gemini 입력 제외: CT-01 조건 교체, CT-03 같은 의미의 표현 수정, E-07 역할·부정 변화 설명을 확인했다. CT-02는 허가 조건이 명시되지 않는다는 설명에 머물러 조건 없는 출입 불가라는 영향이 부족했다.
- 엘리스 입력 제외: CT-01은 조건 변화 자체는 설명했지만 변경된 구절을 남은 단어 오류에도 넣어 인용 검사에서 차단됐다. E-07도 부적절한 notes와 분류 문제가 남았다.
- 엘리스 CT-03은 입력을 제외해도 회원 제한이 사라져 모든 사람이 받을 수 있다는 잘못된 설명을 반환했다. CT-02는 어댑터 반환에 성공했지만 부정문에서 조건 삭제의 영향 설명은 부족했다.
- 소규모 단회·일부 미실행 시험이다. 입력 제외가 일반적으로 좋다거나 comparison이 오류의 유일한 원인이라고 결론 내리지 않는다. 서비스 호출과 브라우저 제공률, 사람의 독립 평가·사용자 효과를 검증한 것이 아니다.

## 도구와 검증

[수동 진단 도구](../../scripts/diagnose-explanation-usage.mjs)에 `baseline`과 `--cases`를 추가했다. 기본 실행은 dry run이며 `--live`에서만 실제 호출한다. 한 실행 최대 6개 서로 다른 사례·사례당 변경 후보 1개, 자동 재시도 없이 서비스·인증·사용량 오류 시 중단한다. 실제 전송된 합성 입력·지침·해시·오류 단계는 기록하지만 키·인증 헤더·원시 제공자 응답 전체는 저장하지 않는다. `worktreeEvaluation: true`인 기록의 실행기 해시는 이번 커밋에 포함되는 스크립트와 대조할 수 있다.

두 모드의 dry run과 중복 `--cases` 거부를 확인했다. 이번 진단 결과는 [#22 병합 검증](../교정%20설명%20평가%20기준.md#issue22-merge-gate)의 14사례×3회 시험을 대신하지 않는다. 그 시험은 아직 실행하지 않았고, 현재 알려진 실패로 인해 병합 조건은 미충족이다.
