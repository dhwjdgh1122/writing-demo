## 결정과 한계

- 두 제공자의 공통 누락인 선택 기준·잔존 단어 문제를 교차 검토로 보완하지 못했다. 같은 배치의 반복이나 제품 자동 교차호출을 채택하지 않는다.
- 과거 자기 검토와 이번 결과는 실행 시점이 다르며 단회 비교다. Gemini의 E-03 부분 개선을 교차 방식의 인과 효과나 모델 우열로 일반화하지 않는다.
- 이번 지침은 과거 재검토용 최대4문장이다. 현재 제품의 1~2문장 계약을 개선한 결과가 아니며, AI 보조 내용 판정은 사람의 판단 도움 검증도 아니다.
- 실행 전 새 입력 보호6개를 포함한 단위/API **164/164**, 타입·문법 검사·양쪽 dry-run을 통과했다. 소프트웨어 검사 성공과 실제 설명 내용 기준은 구분한다.
- [후속 호출 장부](approved-model-calls-continuation-2026-11-22.json)는 누적 **38회**, 보존한 이전19회와 연결한 **57회**다. 수동 사용을 포함한 계정 전체 사용량은 아니다. #22는 미완료, PR #55는 Draft, main은 미병합을 유지한다.
